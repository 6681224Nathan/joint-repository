1. Rectifier (2 min)

StepFormula
1. RMS → peakVm = 1.414 × Vrms, secondary (secondary = primary ÷ turns ratio)
2. Diode dropsVp(out) = Vm − 0.7 (half-wave, center-tapped) · Vm − 1.4 (bridge)
3. No capacitorVdc = 0.318 Vp(out) (half) · 0.636 Vp(out) (full)
4. With capacitorVr = Vp(out)/(fr RL C) · Vdc = Vp(out) − Vr/2 · fr = f (half), 2f (full)
5. PIVhalf: Vm (≈2Vm with C) · center-tapped: 2Vm − 0.7 · bridge: Vm − 0.7
Designbackwards: RL = Vdc/IL → C = IL/(frVr) (round up) → Vp(out) = Vdc + Vr/2 → Vm = Vp(out) + drops → Vrms = Vm/1.414 → turns ratio

2. BJT in 3 rules (2 min)

1. IE = IB + IC, IC = β IB, so IE = (β+1) IB.
2. ON: VBE = 0.7 V, so VB = VE + 0.7.
3. Amplifier needs the active region: VCE > 0.2 V (VC > VB). VCE ≈ 0.2 V means saturated.
Professor's rule: DC analysis first, then AC.

3. DC analysis (5 min): capacitors = OPEN

Delete every capacitor and what hangs off it (vs, Rs, RL, CE). What's left: VCC, R1, R2, RC, RE, transistor.

StepFormula
1. Thévenin of dividerVTH = VCC·R2/(R1+R2), RTH = R1∥R2
2. Base loop (KVL)IB = (VTH − 0.7)/(RTH + (β+1)RE)
3. CurrentsIC = βIB, IE = (β+1)IB
4. VoltagesVE = IERE · VC = VCC − ICRC · VCE = VC − VE
5. CheckVCE > 0.2 V → "active region ✓"
Example (lab circuit): VCC = 12 V, R1 = 47k, R2 = 10k, RC = 2.2k, RE = 560 Ω, β = 100.
VTH = 12×10/57 = 2.105 V · RTH = 8.25 kΩ · IB = 1.405/(8.25k + 101×0.56k) = 21.7 µA
IC = 2.17 mA · IE = 2.19 mA · VE = 1.23 V · VC = 7.23 V · VCE = 6.0 V → active ✓

Shortcut only if β·RE ≥ 10·R2: VB ≈ VTH, IE ≈ (VTH − 0.7)/RE.

4. AC analysis (6 min): capacitors = WIRE, VCC = GROUND

So R1 and R2 both go to ground (R1∥R2), RC and RL both go to ground (RC∥RL), and a bypassed RE disappears (E becomes ground). Replace the transistor with the hybrid-pi model: rπ from B to E, current source gmvπ from C to E.
