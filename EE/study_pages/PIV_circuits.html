PIV in rectifiers (with capacitor, ideal diodes)

Each circuit is frozen at the moment the OFF diode gets squeezed hardest. The small sine wave in each figure shows when that moment is.

Symbols
  • Vm = peak voltage of the transformer secondary. Ideal diodes, so it is also the peak output voltage. For center-tapped, Vm is the peak of each half.
  • PIV = peak inverse voltage = the biggest backwards voltage an OFF diode must block = cathode voltage − anode voltage.
  • Anode = flat side of the triangle, where current enters. Cathode = the bar side, where current leaves.
  • All voltages are measured from the output's ground (0 V).
Colors: green = current flowing (diode ON)  ·  red = OFF diode being squeezed  ·  blue = held at +Vm by the charged capacitor

1. Half-wave + C

  • Moment: negative peak. The top of the coil swings down to −Vm, so the diode is OFF.
  • Cathode: the capacitor charged to +Vm in the previous half and can't empty back through the OFF diode, so it still holds +Vm. It only leaks slowly into RL.
  • PIV = (+Vm) − (−Vm) = 2Vm
  • Other half (positive peak): the diode is ON, recharges C, and there is nothing to block.

2. Full-wave, center-tapped + C

  • Moment: positive peak. The top half pushes current through D1. At the same time, the bottom end of the coil sits at −Vm (the center tap is 0 V).
  • D2's cathode is joined to D1's cathode at node J, which is the output. The capacitor holds J at +Vm.
  • PIV of D2 = (+Vm) − (−Vm) = 2Vm
  • Other half: D2 ON, D1 OFF, and D1 gets the same 2Vm.

3. Full-wave, bridge + C (professor's layout)

  • Moment: positive peak (Vs+ on top). The current path is top corner → D1 → RL → left corner → D2 → bottom corner → back to the coil.
  • D3: anode at the left corner = output − = 0 V. Cathode at the top corner = +Vm. PIV = Vm − 0 = Vm.
  • D4: anode at the bottom corner = 0 V (D2 is ON, an ideal wire to the left corner). Cathode at the right corner = +Vm. PIV = Vm.
  • Why only Vm: no anode is ever left on a bare coil end at −Vm. An ON diode always ties it to 0 V.
  • Other half: D3 and D4 ON, D1 and D2 OFF, with the same Vm.
