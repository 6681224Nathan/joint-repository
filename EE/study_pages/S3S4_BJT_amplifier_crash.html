1. What a BJT is (2 min)

An NPN transistor is a current-controlled valve: a small current into the base (IB) opens a big current from collector to emitter (IC = β·IB). Small in → big out: that's amplification.

Three rules you use everywhere:
1. IC = β·IB · 2. IE = IB + IC = (β+1)·IB (everything leaves through the emitter) · 3. ON means VBE = 0.7 V, so VB = VE + 0.7

2. The three modes (1 min)

ModeTestUsed as
CutoffVBE < ~0.5 V, IC = 0switch OFF
ActiveVBE = 0.7 V and VCE > 0.2 V (VC > VB)amplifier (this is what we want)
SaturationVBE = 0.7 V, VCE ≈ 0.2 V (VC < VB)switch ON

So every amplifier problem ends its DC part with: "VCE = … V > 0.2 V → active region ✓".

3. The circuit you'll get (slide 16 / Lab 4)

Professor's rule: DC analysis first (to get IC and check active), then AC analysis (gain, Zi, Zo). Two different pictures of the same circuit:
DC picture: every capacitor = open. AC picture: every capacitor = wire, VCC = ground.

4. DC analysis (5 min)

Step A: draw the DC picture. Capacitors are open, so vs, Rs, RL and CE all disappear. Step B: replace R1–R2 by its Thévenin equivalent (S0!): that's what makes the base easy.

1. VTH = 12 × 10/57 = 2.105 V · 2. RTH = 47k∥10k = 8.25 kΩ

Shortcut (only if β·RE ≥ 10·R2): ignore IB, so VB ≈ VTH and IE ≈ (VTH − 0.7)/RE. Here β·RE = 56k < 100k, so use the full formula.

5. DC load line and Q-point (1 min, lecture 5 slides 6–9)

Same trick as the diode (S1): two "pretend" points. Transistor = wire (VCE = 0): IC(sat) = VCC/(RC + RE). Transistor = gap (IC = 0): VCE(cutoff) = VCC. The Q-point (VCE, IC) sits on that line. For the biggest undistorted output, it should be near the middle; too close to either end and the output clips (slide 9).

6. AC analysis (6 min)

Step A: AC picture. Capacitors → wire, VCC → ground. So R1 and R2 both end at ground (they're in parallel), RC and RL both end at ground (parallel), and CE shorts RE (emitter = ground).
Step B: replace the transistor by the hybrid-pi model (it's given in the exam; know what each part means):

Gain with variables (the class assignment)

Input side: the emitter is ground, so vπ = vin.
Output side (no load): the current gmvπ flows down through RC from the output node to ground, so vo = −(gmvπ)·RC. The minus is because the current flows into the output node's resistor from above, pulling the node below ground.
So Av = vo/vin = −gmRC. With a load: RC → RC∥RL. The minus sign = output is inverted (180°), which is exactly what Lab 4 showed.

8. Practice (8 min, quiz style)

Same circuit as section 3, RE bypassed. VCC = 15 V, R1 = 56 kΩ, R2 = 12 kΩ, RC = 3.3 kΩ, RE = 1 kΩ, β = 150, RL = 10 kΩ, Rs = 1 kΩ.
Find: (a) VTH, RTH, IB (b) IC, VCE, mode (c) the load-line end points (d) gm, rπ (e) Zi, Zo (f) Av no load and with RL (g) Avs.
Solution

(a) VTH = 15 × 12/68 = 2.65 V · RTH = 56k∥12k = 9.88 kΩ · IB = (2.65 − 0.7)/(9.88k + 151 × 1k) = 1.947/160.9k = 12.1 µA

(b) IC = 150 × 12.1µ = 1.82 mA · IE = 1.83 mA · VE = 1.83 V · VC = 15 − 1.82 × 3.3 = 9.01 V · VCE = 7.18 V > 0.2 → active ✓

(c) IC(sat) = 15/(3.3k + 1k) = 3.49 mA · VCE(cutoff) = 15 V · Q-point (7.18 V, 1.82 mA), close to the middle ✓

(d) gm = 1.82m/26m = 69.8 mS · rπ = 150/0.0698 = 2.15 kΩ

(e) Zi = 9.88k∥2.15k = 1.77 kΩ · Zo = RC = 3.3 kΩ

(f) No load: −0.0698 × 3300 = −230 · With RL: 3.3k∥10k = 2.48k → −0.0698 × 2480 = −173

(g) Avs = −173 × 1.77/(1.77 + 1) = −111

Checklist: DC (C open) → Thévenin → IB with (β+1)RE → IC, VCE → "active ✓" → AC (C wire, VCC ground) → gm from DC IC → rπ → Zi, Zo → Av with the minus sign → Avs if Rs is given. Write each formula before the numbers.
